# Gracebound

Current release: **0.0.2 Beta**.

Portable Elden Ring boss tracker for Windows. Includes 207 base-game and Shadow of the Erdtree bosses, character save import, offline live tracking, region filters, spoiler hiding, and completion tracking.

## Download and run

Download **Gracebound-Windows-x64.zip** from the [latest release](https://github.com/itsMohammedAli/gracebound-releases/releases/tag/v0.0.2). Extract the entire ZIP to a folder of your choice, then run **gracebound.exe**. Keep the DLLs and data folder together. No installer or administrator privileges are needed.

## Updates

Gracebound checks at startup and every six hours. Download portable update verifies the ZIP checksum and reveals it in Explorer. Extract the new version, close the old app, and run the new executable. Preferences are stored in your Windows user profile.

Live tracking requires an offline game launched without Easy Anti-Cheat. Use save import for protected sessions. Gracebound does not edit game saves or memory.

Undefeated bosses start concealed as Veiled Boss. Click the white eye button to reveal one boss; other bosses stay concealed. Reveals carry across grid and list views.
