# Gracebound

An Elden Ring boss completion companion for Windows, covering 207 base-game and Shadow of the Erdtree bosses.

## Download

Download **Gracebound-Setup.exe** from the [latest release](https://github.com/itsMohammedAli/gracebound-releases/releases/latest). Run setup, then launch Gracebound from the Start menu. Installation does not require administrator privileges.

## Features

- Save import with character selection and a 10-second refresh.
- Offline Windows live tracking.
- Region grouping, search, grid/list views, and accurate completion percentages.
- Hide defeated bosses or conceal undefeated boss names and artwork.
- Automatic update checks with SHA-256 download verification.

Live tracking requires a game launched offline without Easy Anti-Cheat. Use save import for protected sessions. Gracebound reads progress without editing game saves or memory.

## Updates

The app checks at startup and every six hours. Use **Check for updates** for a manual check, then choose **Download & install** when a newer version is available. Checksums are also included in each release for manual verification.

This repository hosts public Windows release downloads.
